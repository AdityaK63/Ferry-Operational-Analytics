# Ferry Capacity Utilization & Operational Efficiency Analytics System

## Project Overview

This project analyzes Toronto Island Ferry ticket sales and redemption activity to identify operational patterns, peak activity periods, and insights that can support data-driven operational planning.

The project uses Python for data cleaning, exploratory data analysis, KPI analysis and visualization, and Power BI for interactive dashboard development.

## Objectives

- Analyze ferry ticket sales and redemption activity.
- Identify peak activity hours, days and months.
- Compare weekday and weekend activity.
- Explore operational activity patterns using data analytics.
- Build an interactive dashboard using Power BI.
- Provide data-driven insights and recommendations.

## Key Findings

- 12 PM was identified as the busiest hour based on average recorded activity.
- Saturday was the busiest day based on average recorded activity.
- August recorded the highest average monthly activity.
- Weekend average activity was higher than weekday average activity.
- Unusually high activity records require further validation.

## Dashboard

The project includes an interactive Power BI dashboard featuring:

- Total Sales
- Total Redemptions
- Average Total Activity
- Average Activity by Hour
- Average Activity by Day
- Monthly Sales and Redemption Comparison
- Activity Level Distribution
- Weekday vs Weekend Analysis

## Limitations

The dataset contains ticket sales and redemption records at timestamp intervals. It does not directly contain ferry vessel capacity or passenger counts per departure.

Therefore, this project analyzes ticket activity patterns as operational activity indicators rather than measuring actual ferry capacity utilization.

Extremely high records should be validated before being interpreted as normal operational demand.

## Conclusion

This project demonstrates how data analytics techniques can be used to explore ferry ticket activity, identify temporal patterns, analyze operational indicators and develop interactive dashboards to support data-driven decision-making.
