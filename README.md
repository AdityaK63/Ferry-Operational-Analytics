## Project Dashboard

The interactive Power BI dashboard provides an overview of ferry ticket activity and operational patterns.

### Dashboard Features

- Sales and redemption KPIs
- Hourly activity analysis
- Daily activity analysis
- Monthly sales and redemption trends
- Activity level distribution
- Weekday vs weekend comparison
- Year, month and day filters

### Project Files

- Python notebook – data cleaning, analysis and visualization
- Cleaned dataset – prepared dataset for analysis
- KPI summary – key project metrics
- Hourly, daily and monthly analysis exports
- Peak activity intervals
- Activity classification
- Power BI dashboard screenshot

### Recommendations

- Monitor peak activity periods.
- Consider weekend activity patterns during operational planning.
- Review seasonal activity trends.
- Validate unusually high recorded activity values before operational interpretation.
